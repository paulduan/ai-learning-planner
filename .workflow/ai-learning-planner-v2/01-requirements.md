## 产物内容

### 概述

在现有「AI 规划 → 阶段学习 → 苏格拉底教学 → Q&A 评估 → 闯关解锁」闭环之上，补齐六个能力维度：

| 缺口 | 对应模块 |
|------|---------|
| 学了就忘 | 遗忘曲线复习 |
| 知识碎片化 | 知识图谱 |
| 缺乏可展示产出 | 实战项目 |
| 不了解自身学习模式 | 数据分析 |
| 内容难度不匹配 | 自适应难度 |
| 成果无法对外呈现 | 成果导出 |

### 产品原则

1. **实践优先**：项目驱动 > 纯阅读
2. **苏格拉底式**：复习、评估均重「为什么/怎么做」
3. **连接现实**：项目与真实场景绑定
4. **通用学科**：不假设用户学的是编程
5. **本地优先**：SQLite + 本地文件
6. **用户掌控**：复习/自适应/数据采集均可关闭

### 数据模型变更

#### 新增表

1. **review_schedule** — 复习计划节点
2. **review_session** — 复习会话记录
3. **knowledge_concept** — 知识概念节点
4. **knowledge_relation** — 概念关系
5. **stage_project** — 阶段实战项目
6. **learning_session** — 学习行为会话
7. **mastery_profile** — 掌握度画像
8. **adaptive_adjustment** — 自适应调整记录
9. **export_record** — 导出历史

#### 修改表

- **learning_plan**: +review_enabled, +adaptive_enabled, +analytics_enabled, +review_interval_preset
- **system_config**: +review_notifications, +default_review_interval_preset
