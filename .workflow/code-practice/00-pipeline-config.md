## 功能需求摘要

**用户需求**: 新增「从代码学习」功能，和现有的「从书本学习」并列

**核心流程**:
1. 用户输入本地项目目录路径
2. 后端扫描项目文件结构，读取源代码文件
3. AI 分析代码架构、设计模式、模块划分
4. 生成阶段化的代码学习计划（4-6 个阶段）
5. 通过现有的苏格拉底式问答教学系统进行代码教学

**实现范围**:
- 后端: `generatePlanFromCode()` AI 函数 + `/api/plan/generate-from-code` API 路由
- 前端: `/plan/new` 页面新增「从代码学习」入口和步骤
- 复用: 现有的 stage/chat/assess/review 全部复用

## 技术决策

1. **代码读取策略**: 递归扫描项目目录，过滤 `node_modules/.git` 等，按文件扩展名筛选源码，限制总字符数 80K
2. **支持语言**: JS/TS/Go/Python/Java/Rust/C++/Swift/PHP/Ruby 等主流语言
3. **文件树展示**: 最多 4 层深度，用于给 AI 提供项目结构上下文
4. **路径验证**: 前端先调用 `validate_only` 接口验证路径有效性
5. **无 DB 改动**: 复用现有 `learning_plan` + `stage` 表结构，无需新增表
